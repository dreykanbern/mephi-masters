# Задание 51 — Подсчёт слов в тексте

Задача 2 из блока о работе с файлами.

Метод `getCountWords()` возвращает количество слов в `text.txt`. Слово состоит из букв и цифр. Апостроф `'` или `’` между буквами или цифрами входит в слово, поэтому `It's` считается одним словом. Пробельные символы и остальная пунктуация разделяют слова. [Пример входного файла](text.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Программа выводит `4`.
