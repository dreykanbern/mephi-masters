# Задание 33 — Переворот одного слова

Задача 6 из блока о массивах и строках.

Запрашивать одно слово и выводить его в обратном порядке. Пробелы по краям удаляются. Пустой ввод и несколько слов вызывают сообщение `Введите корректное имя!` и повторный запрос, как в примере условия.

Метод `reverseWord` превращает слово в массив `char[]` и меняет местами симметричные символы. Для ввода `абра кадабра`, затем `кадабра` программа сначала сообщает об ошибке, затем выводит `Слово наоборот - арбадак`.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
