# Задание 45 — Символы строк по общему индексу

Задача 18 из блока о массивах и строках.

Из каждой строки публичного массива `strings` взять символ с индексом `nth` и сохранить в публичном массиве `Character[] output`. Исходные строки и их порядок сохранены.

`nth = 0`: индексы начинаются с нуля, поэтому программа берёт первые символы. В исходном наборе для всех строк допустимы индексы от `0` до `7`. Результат печатается через `Arrays.stream(output).forEach(System.out::print)`.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
CHPHLVCRGOAAMBFRPTFAEG
```
