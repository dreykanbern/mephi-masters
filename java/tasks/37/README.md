# Задание 37 — Склад на двенадцать предметов

Задача 10 из блока о массивах и строках.

Хранить названия предметов в массиве на 12 ячеек. Команды вводятся отдельной строкой:

- `Проверить`, затем название: выводит `Есть` или `Нет`.
- `Добавить`, затем название: сообщает об успешном добавлении, дубликате или заполненном складе.
- `Удалить`, затем название: удаляет предмет либо сообщает, что его нет.
- `Показать`: выводит все текущие предметы.
- `Выход` или `0`: завершает программу.

Регистр команд не важен. Названия сравниваются через `equals`, с учётом регистра; пробелы по краям удаляются. Пустое название отклоняется. После удаления оставшиеся элементы сдвигаются, последняя занятая ячейка очищается, а место снова доступно для добавления. Дубликат распознаётся и на заполненном складе.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
