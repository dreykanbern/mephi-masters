# Задание 49 — Шифрователь текстов

Зашифруйте переданную строку заменой символов и восстановите её. Если указано время отправки, зашифруйте и восстановите его тем же ключом.

В строках `ALPHABET` и `KEY` соответствующие символы стоят на одинаковых позициях. Шифр заменяет русские и английские буквы с сохранением регистра, а также цифры. Пробелы, пунктуация и символы вне ключа сохраняются. Цикл применяет `String.replace()` к исходным символам по одному, поэтому результат каждой подстановки сразу добавляется в ответ. Для расшифровки метод `decrypt` меняет строки ключа местами.

## Запуск на Java 17

Скомпилируйте программу из каталога `java/tasks/49`. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Введите сообщение первой строкой. Второй строкой укажите время отправки в 24-часовом формате, например `09:30` или `09:30:15`. Если время не нужно, нажмите Enter.

Для расшифровки запустите программу с аргументом `decrypt` и введите зашифрованное сообщение и время в том же порядке.

```bash
java -cp out Main decrypt
```

Сообщение `Привет, Java! Ёж 🦔` и время `09:30` превращаются в `Олъешж, Qzez! Щз 🦔` и `90:69`. Режим `decrypt` восстанавливает оба значения.
