# Задание 48 — Шифр Цезаря

Задача 21 из блока о массивах и строках.

Реализовать публичные методы `encrypt(String text, int shift)` и `decrypt(String text, int shift)`. Сдвигаются только английские буквы `A–Z` и `a–z`; регистр, знаки препинания, пробелы и остальные символы сохраняются. Переход через конец алфавита выполняется по кругу.

Сдвиг нормализуется через `Math.floorMod(shift, 26)`, поэтому допускаются отрицательные и большие значения, включая `Integer.MIN_VALUE`. Дешифрование использует метод шифрования с обратным нормализованным сдвигом.

При сдвиге `5` строка `ABC VWXYZ` превращается в `FGH ABCDE`. В `main` шифруется исходный текст `Lorem ipsum` из условия; значение публичного поля `text` сохранено.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
