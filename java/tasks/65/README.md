# Задание 65 — Группировка файлов по расширению

Задача 16 из блока о работе с файлами.

Метод `solution()` читает из `files.txt` имена файлов и их размеры в `B`, `KB` или `MB`. Он группирует файлы по расширениям `BMP`, `TXT` и `ZIP` и записывает в `output.txt` группы и имена в алфавитном порядке.

После имён файлов каждой группы идёт разделитель и строка `Summary` с суммарным размером. Размеры сначала складываются в байтах. Результат выводится в `MB` при сумме от одного мегабайта, в `KB` при сумме от одного килобайта и в байтах при меньшей сумме. Размер округляется до целого. В одном `KB` 1024 байта, а в одном `MB` 1024 `KB`. [Пример входного файла](files.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

В `output.txt` появятся следующие строки.

```text
input.txt
output.txt
----------
Summary: 4 KB

scratch.zip
----------
Summary: 5 MB
```
