# Задание 41 — Проверка нового пароля по истории

Задача 14 из блока о массивах и строках.

Запросить пароль, проверить его отсутствие среди предыдущих паролей и длину не менее 8 символов. При нарушении условия объяснить причину и предложить повторный ввод. При успехе вывести `Security password verified success` и завершить программу.

Максимальная длина не ограничена. История паролей: `password123`, `qwerty123`, `letmein123`. Совпадение проверяется через `equals`, с учётом регистра.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
