# Задание 63 — Маршрут грибника

Задача 14 из блока о работе с файлами.

В `forest.txt` записана карта из 10 строк и 10 столбцов, значения разделены `;`. Грибник начинает в верхней левой клетке и движется вправо или вниз. Метод `findMaxQuantity()` возвращает максимальную сумму грибов, которую можно собрать по пути в правую нижнюю клетку. Для каждой клетки складываются её значение и лучший результат из клеток сверху и слева. [Пример входного файла](forest.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Программа выводит `1204`.
