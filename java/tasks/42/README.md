# Задание 42 — Сто чисел с чередующимися знаками

Задача 15 из блока о массивах и строках.

Заполнить публичный массив `numbers` на 100 ячеек последовательностью `[1, -2, 3, -4, …, 99, -100]`. Числа формируются циклом: нечётные положительные, чётные отрицательные. Модификаторы доступа и размер массива сохранены.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
