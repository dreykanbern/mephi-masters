# Задание 34 — Разворот массива строк без второго массива

Задача 7 из блока о массивах и строках.

Изменить порядок элементов массива `String[]` на обратный, не создавая второй массив. Метод `reverse` обменивает симметричные элементы через временную переменную. Работает для чётной и нечётной длины, а также пустого массива.

Исходный массив: `{"Java", "массивы", "строки", "методы", "циклы"}`.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
[циклы, методы, строки, массивы, Java]
```
