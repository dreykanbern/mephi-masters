# Задание 29 — Имя пользователя и длина пароля

Задача 2 из блока о массивах и строках.

Запросить имя и пароль. Допустимая длина пароля — от 8 до 15 символов включительно. При слишком коротком или длинном пароле программа объясняет причину и запрашивает пароль повторно. При корректном вводе выводятся имя и пароль.

Имя считывается одной строкой. Пароль проверяется без удаления пробелов: они тоже входят в длину. Например, после имени `Иван` можно ввести `short`, затем `12345678`: первый пароль будет отклонён, второй — принят.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
