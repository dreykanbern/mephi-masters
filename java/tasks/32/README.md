# Задание 32 — Сумма и максимум дробных чисел

Задача 5 из блока о массивах и строках.

В пакете `modul3` создать класс `Main` и метод с массивом дробных чисел `{1.3, 3.2, 5.1, 4.7}`. Первый цикл выводит все элементы, второй находит сумму и наибольший элемент.

Начальное значение максимума берётся из первого элемента массива.

Решение на Java 17. Исходный код: [`Main.java`](src/modul3/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/modul3/*.java
java -cp out modul3.Main
```

Результат:

```text
1.3
3.2
5.1
4.7
Сумма чисел массива: 14.3
Наибольший элемент: 5.1
```
