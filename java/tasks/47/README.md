# Задание 47 — Последовательное сокращение строки

Задача 20 из блока о массивах и строках.

Печатать строку и на каждом шаге удалять первый и последний символы, пока не останется один или два символа. Изменяется само публичное поле `string`.

Исходное значение — `helloworld`. После выполнения поле содержит `ow`, его длина равна `2`. Для нечётной длины остаётся один символ.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
helloworld
elloworl
llowor
lowo
ow
```
