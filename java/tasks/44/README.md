# Задание 44 — Треугольник Паскаля в зубчатом массиве

Задача 17 из блока о массивах и строках.

Сформировать треугольник Паскаля из `size` строк в публичном массиве `ints`. Длина строки с индексом `i` — `i + 1`. Крайние элементы равны `1`, внутренние — сумме двух соседних элементов предыдущей строки.

Исходное значение `size = 3` и модификаторы полей сохранены. Вывод выполняется построчно через `Arrays.toString`, без центрирования.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
[1]
[1, 1]
[1, 2, 1]
```
