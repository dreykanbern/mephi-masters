# Задание 61 — Доход и налог торговца

Задача 12 из блока о работе с файлами.

Метод `findMerchant(String merchant)` читает таблицу `outcome.txt` и выводит для каждой сделки указанного торговца товар, количество, цену и доход через запятую. Доход равен произведению количества на цену. В последней строке метод выводит налог в размере 15 % от суммы доходов. [Пример входного файла](outcome.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для торговца `Cherevik` программа выводит следующие строки.

```text
hemp,20,5,100
straw,12,6,72
tax: 25.8
```
