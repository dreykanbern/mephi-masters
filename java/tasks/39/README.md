# Задание 39 — Домен электронной почты

Задача 12 из блока о массивах и строках.

Запросить адрес электронной почты и вывести часть после `@`. Например, `ivan@example.com` даёт `example.com`.

Перед проверкой удаляются пробелы по краям. Проверяется наличие ровно одного `@`, непустых частей до и после него и отсутствие пробельных символов внутри адреса. При неверном вводе программа просит повторить адрес. Регистр домена сохраняется.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
