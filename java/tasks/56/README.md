# Задание 56 — Ритм танца

Задача 7 из блока о работе с файлами.

В первой строке `dance.txt` указано количество шагов в одном ритме. Далее записаны длительности танцев в шагах, по одному числу на строку. Для каждого танца метод `dance()` делит его длительность на длину ритма и записывает в `rhythm.txt` количество полных повторов и остаток через пробел. [Пример входного файла](dance.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

В `rhythm.txt` появятся следующие строки.

```text
6 0
3 3
2 1
24 2
```
