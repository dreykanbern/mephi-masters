# Задание 62 — Перевод сообщения в двоичный код

Задача 13 из блока о работе с файлами.

Метод `translate()` читает `message.txt` и возвращает строку, где заглавные английские буквы `A–Z` заменены семибитными кодами ASCII. Например, `A` становится `1000001`, а `Z` — `1011010`. Пунктуация, табуляции, переводы строк и прочие символы сохраняются. [Пример входного файла](message.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Программа выводит переведённое сообщение.

```text
101000010100101001001101011010001011010100, 100101110000011001011 1010101 10101001000101100001010110011000001 1000100100010110011001000001?
```
