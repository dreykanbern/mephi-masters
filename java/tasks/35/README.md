# Задание 35 — Меню обработки текста

Задача 8 из блока о массивах и строках.

Обрабатывать текст из условия через повторяющееся меню:

1. Удалить обычные пробелы.
2. Выбрать верхний или нижний регистр.
3. Вывести количество символов.
0. Выйти из программы.

Операции применяются к текущему тексту: результат сохраняется между пунктами меню. При удалении пробелов абзацы сохраняются. `length` учитывает пробелы, знаки препинания и переводы строк. Для смены регистра используется `Locale.ROOT`. Неизвестная команда вызывает сообщение об ошибке, после которого меню доступно снова.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```
