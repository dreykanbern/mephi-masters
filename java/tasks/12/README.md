# Задание 12 — Индекс массы тела

Решение задания на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Введите вес в килограммах и рост в метрах. В десятичных числах используйте точку. Категория определяется после округления ИМТ до десятых.
