# Задание 28 — Третий элемент отсортированного массива

Задача 1 из блока о массивах и строках.

Создать массив `{5, 24, 3, 66, 38, 16, 27}`, отсортировать его по возрастанию и вывести третий элемент. После `Arrays.sort` массив равен `[3, 5, 16, 24, 27, 38, 66]`. Элемент с индексом `2` — `16`.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
16
```
