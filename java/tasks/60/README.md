# Задание 60 — Решение арифметических примеров

Задача 11 из блока о работе с файлами.

Метод `solve()` читает из `arithmetic.txt` по одному выражению на строку. Выражение состоит из двух целых чисел и оператора `+`, `-` или `*`, разделённых пробелами. Метод дописывает к каждому выражению знак равенства и результат, затем сохраняет строки в `answers.txt`. [Пример входного файла](arithmetic.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

В `answers.txt` появятся следующие строки.

```text
5 + 3 = 8
2 * 8 = 16
13 - 7 = 6
```
