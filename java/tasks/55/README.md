# Задание 55 — Отбор строк по средней длине

Задача 6 из блока о работе с файлами.

В первой строке `data.txt` задано допустимое отклонение от средней длины. Метод `solution()` делит суммарную длину остальных строк на их количество нацело. В `output.txt` он записывает среднюю длину, а затем все строки, длина которых отличается от неё не более чем на заданное число. Если подходящих строк нет, файл содержит одну строку со средней длиной. [Пример входного файла](data.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

В `output.txt` появятся следующие строки.

```text
5
apple
banana
cherry
date
```
