# Задание 53 — Числа, совпадающие со своими позициями

Задача 4 из блока о работе с файлами.

Метод `writeOrder()` читает по одному числу из каждой строки `numbers.txt`. Нумерация строк начинается с единицы. Числа, совпавшие с номером строки, записываются через пробел в `output.txt`. При отсутствии совпадений метод записывает `0`. [Пример входного файла](numbers.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

В `output.txt` появится `1 2 4`. Для чисел `7`, `6`, `7` файл будет содержать `0`.
