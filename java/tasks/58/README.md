# Задание 58 — Рост урожайности

Задача 9 из блока о работе с файлами.

Метод `solution(String district, int fromYear, int toYear)` находит нужные годы в заголовке `crop_volumes.txt`. Он записывает в `data.txt` название и два значения для каждого региона указанного округа, где урожайность выросла строго более чем на 4 %. Если подходящих строк нет, в файле остаётся только заголовок. [Пример входного файла](crop_volumes.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для Северо-Западного округа и годов `2018` и `2019` в `data.txt` появятся следующие строки.

```text
Part;2018;2019
Республика Коми;2.0;2.7
```
