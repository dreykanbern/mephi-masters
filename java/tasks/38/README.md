# Задание 38 — Замена двоек в учебном дневнике

Задача 11 из блока о массивах и строках.

Заменить все оценки `2` на `5` в массиве оценок Сидорова Ивана. Метод `replaceTwosWithFives` изменяет исходный массив и сохраняет остальные оценки.

Начальные оценки: `{5, 2, 4, 3, 2, 5, 2}`.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
[5, 5, 4, 3, 5, 5, 5]
```
