# Задание 30 — Сумма баллов участников

Задача 3 из блока о массивах и строках.

Для пяти участников — Саши, Игоря, Миши, Коли и Владимира — просуммировать баллы по пяти дисциплинам. Каждая строка двумерного массива содержит баллы одного участника. Метод `summarizeScores` формирует одномерный массив строк вида `<имя>  <сумма баллов>`, который выводится построчно.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
Саша  40
Игорь  43
Миша  40
Коля  43
Владимир  44
```
