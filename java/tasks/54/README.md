# Задание 54 — Проверка строк на палиндромы

Задача 5 из блока о работе с файлами.

Метод `arePalindromes()` возвращает `true`, если все строки в `strings.txt` читаются одинаково в обоих направлениях, и `false` в остальных случаях. При сравнении игнорируются пробельные символы и регистр букв. [Пример входного файла](strings.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Программа выводит `true`.
