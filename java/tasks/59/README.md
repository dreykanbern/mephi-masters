# Задание 59 — Площадь под графиком

Задача 10 из блока о работе с файлами.

В каждой строке `points.txt` записаны целые координаты `X Y`. Точки лежат в первой четверти и отсортированы по `X`. Метод `findSquare()` возвращает `double` и приближает площадь под графиком суммой площадей трапеций между соседними точками. Площадь каждой трапеции равна полусумме координат `Y`, умноженной на разность координат `X`. [Пример входного файла](points.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для точек `(1, 1)` и `(2, 2)` программа выводит `1.5`.
