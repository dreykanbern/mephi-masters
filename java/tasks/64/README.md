# Задание 64 — Вырубка деревьев по кругу

Задача 15 из блока о работе с файлами.

В `trees.txt` через пробел записана толщина деревьев вокруг посёлка. Метод `findMaxProfit()` вычисляет максимальную суммарную толщину срубленных деревьев при условии, что соседние деревья рубить одновременно нельзя. Первое и последнее также считаются соседями. Для расчёта сравниваются варианты с исключением первого и последнего дерева. Если дерево одно, можно срубить его. Из двух деревьев можно срубить одно. [Пример входного файла](trees.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для списка `2 3 2` программа выводит `3`, а для `1 2 3 1` выводит `4`.
