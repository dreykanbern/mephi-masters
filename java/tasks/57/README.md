# Задание 57 — Анализ результатов ЕГЭ

Задача 8 из блока о работе с файлами.

Метод `solution(double n)` читает таблицу `EGE.txt` с заголовками и разделителем `;`. Он выводит названия предметов, для которых значение в столбце `Passed in %` больше или равно `n`. Каждый предмет выводится отдельной строкой. [Пример входного файла](EGE.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Программа вызывает `solution(80)` и выводит `Math`.
