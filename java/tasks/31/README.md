# Задание 31 — Книжный магазин

Задача 4 из блока о массивах и строках.

Создать программу в пакете `bookstore`. Класс `Book` хранит название, целочисленную цену и год издания. Картотека в `Main` представлена массивом `Book[]` на три книги.

Статический метод `findBook` проверяет совпадение названия через `String.equals` и года издания. Метод `addBook` сообщает о найденном дубликате либо добавляет книгу в свободную ячейку. Для заполненного массива выводится `Картотека заполнена.`. Книги с одинаковым названием и разными годами считаются разными изданиями; цена не входит в проверку совпадения.

В `main` показаны добавление, повторное добавление, другое издание и переполнение. Метод `printBooks` выводит название, год и цену каждой книги через `printf`, без конкатенации.

Решение на Java 17. Исходный код: [`Book.java`](src/bookstore/Book.java), [`Main.java`](src/bookstore/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/bookstore/*.java
java -cp out bookstore.Main
```
