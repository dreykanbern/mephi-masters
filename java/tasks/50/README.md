# Задание 50 — Сумма покупок в чеке

Задача 1 из блока о работе с файлами.

Метод `getReceipt()` читает `receipt.txt`. В каждой строке через `;` записаны название товара, количество и цена за штуку. Метод суммирует произведения количества на цену и возвращает сумму с точкой и двумя знаками после неё. [Пример входного файла](receipt.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Программа выводит `250.00`.
