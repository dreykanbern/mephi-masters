# Задание 36 — Обратный порядок и сортировка по убыванию

Задача 9 из блока о массивах и строках.

Для массива `{27, 97, 86, 88, 31, 46, 59, 48, 16, 4}` сначала вывести элементы в обратном порядке, затем отсортировать по убыванию. В обоих случаях меняется исходный массив; метод `reverse` обменивает симметричные элементы.

Решение на Java 17. Исходный код: [`Main.java`](src/Main.java).

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
В обратном порядке: [4, 16, 48, 59, 46, 31, 88, 86, 97, 27]
По убыванию: [97, 88, 86, 59, 48, 46, 31, 27, 16, 4]
```
