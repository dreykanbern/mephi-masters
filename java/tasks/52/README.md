# Задание 52 — Произведение кратных чисел

Задача 3 из блока о работе с файлами.

Метод `getMul()` читает число `N` из первой строки `data.txt` и список делителей из второй. Он перемножает натуральные числа от `1` до `N` включительно, кратные хотя бы одному делителю. Каждое число входит в произведение один раз. Результат имеет тип `BigInteger`. Пустое произведение равно `1`. [Пример входного файла](data.txt)

## Запуск на Java 17

Выполните команды из каталога задачи. [Исходный код](src/Main.java)

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для `N = 10` и делителей `4` и `5` программа выводит `1600`.
