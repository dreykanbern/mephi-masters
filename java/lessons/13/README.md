# Урок 13 — Проверка имени в отдельном методе

Задание 5 из блока о строках. Вынести всю проверку имени в метод `checkUserName`.

Решение на Java 17: [`Main.java`](src/Main.java). Метод принимает выбранное и существующее имена, сравнивает их через `equalsIgnoreCase` и выводит сообщение. В `main` остаётся вызов метода.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
Выберите другое имя пользователя
```

Для имени `Вован Иванов` метод выведет `Отличное имя!`.
