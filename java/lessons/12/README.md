# Урок 12 — Сообщение о доступности имени

Задание 4 из блока о строках. При совпадении имён без учёта регистра вывести `Выберите другое имя пользователя`, иначе — `Отличное имя!`.

Решение на Java 17: [`Main.java`](src/Main.java). В условии используется `equalsIgnoreCase`.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Для имени `Иван Иванов` результат:

```text
Выберите другое имя пользователя
```

Если заменить `Иван` на `Вован`, программа выведет `Отличное имя!`.
