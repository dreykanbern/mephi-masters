# Урок 16 — Методы изменения строк и полное имя

Задание 8 из блока о строках. Три самостоятельные программы на Java 17. У каждой свой класс `Main`, поэтому подпункты компилируются отдельно.

## 1. Удаление пробелов

Исходный код: [`1/src/Main.java`](1/src/Main.java).

Метод `removeWhiteSpaces` удаляет все обычные пробелы через `replace(" ", "")`, без посимвольного обхода строки.

Запуск из каталога `lessons/16`:

```bash
javac -encoding UTF-8 --release 17 -d out/1 1/src/*.java
java -cp out/1 Main
```

Результат:

```text
АрозаупаланалапуАзора
```

## 2. Проверка полного имени

Исходный код: [`2/src/Main.java`](2/src/Main.java).

Метод `checkName` удаляет пробелы по краям через `trim`, разделяет строку через `split("\\s+")` и проверяет, что получилось ровно три слова. Повторные пробелы и табуляции служат разделителями. Дефис остаётся частью слова: `Анна-Мария Иванова Петровна` — корректный ввод.

Запуск из каталога `lessons/16`:

```bash
javac -encoding UTF-8 --release 17 -d out/2 2/src/*.java
java -cp out/2 Main
```

Введите полное имя одной строкой. Пустая строка, одно, два или четыре и более слова вызывают сообщение `Введите корректное имя!` и повторный ввод. При корректном имени программа завершается без дополнительного сообщения. Если ввод закончился, программа также завершается.

## 3. Форматирование полного имени

Исходный код: [`3/src/Main.java`](3/src/Main.java).

После такой же проверки метод `formatName` приводит первую букву каждого слова к верхнему регистру, остальные — к нижнему. Метод `sortByLength` сортирует слова по возрастанию длины. Слова одинаковой длины сохраняют исходный порядок, дефис не разделяет слово. Результат объединяется через один пробел с помощью `String.join`.

Запуск из каталога `lessons/16`:

```bash
javac -encoding UTF-8 --release 17 -d out/3 3/src/*.java
java -cp out/3 Main
```

Например, для ввода `  сЕРГЕЕВИЧ   иВАН  пЕТРОВ  ` результат:

```text
Иван Петров Сергеевич
```

При неверном числе слов программа просит ввести имя снова. Проверяется число слов; дополнительных ограничений на символы имени в условии нет.
