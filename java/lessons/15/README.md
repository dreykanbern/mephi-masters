# Урок 15 — Длина имени без пробелов

Задание 7 из блока о строках. После длины уникального имени вывести число символов без пробелов. Проверка должна работать и для имени из трёх слов.

Решение на Java 17: [`Main.java`](src/Main.java). Метод `checkUserName` перебирает символы с помощью `length` и `charAt`, считая только символы, отличные от пробела. Число пробелов заранее не задаётся.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат для имени `Вован Иванов Иванович`:

```text
Отличное имя!
Ваше имя имеет длину 21 символов
А без пробелов ваше имя занимает 19 символов
```

Для имени `Вован Иванов` длины равны `12` и `11`, а для занятого имени `Иван Иванов` выводится только просьба выбрать другое имя.
