# Урок 9 — Третий символ строки

Задание 1 из блока о строках. Напечатать третий символ слова `Sometimes`.

Решение на Java 17: [`Main.java`](src/Main.java). Метод `charAt(2)` возвращает третий символ, поскольку индексы начинаются с нуля.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
m
```
