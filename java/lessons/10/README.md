# Урок 10 — Сравнение имён с учётом регистра

Задание 2 из блока о строках. Сравнить имена `Иван Иванов` и `иван иванов` в системе, где регистр важен.

Решение на Java 17: [`Main.java`](src/Main.java). Метод `equals` учитывает регистр и выводит `false`: имена различаются, поэтому пользователь может выбрать имя `Иван Иванов`.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
false
```
