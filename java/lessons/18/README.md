# Урок 18 — Массив байтов в памяти

## Задание 10

Напишите программу, которая с помощью `ByteArrayOutputStream` формирует в памяти массив байтов из чисел 1, 2, 3, 4, 5, а затем выводит содержимое этого массива на экран, например через `Arrays.toString()`.

<details>
<summary>Посмотреть решение</summary>

Вызов `write(int)` записывает младшие 8 бит числа в поток. Метод `toByteArray()` возвращает копию записанных байтов, а `Arrays.toString()` форматирует массив для вывода. [Код решения](src/Main.java)

</details>

## Запуск на Java 17

Выполните команды из каталога `java/lessons/18`.

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

## Ожидаемый вывод

```text
[1, 2, 3, 4, 5]
```
