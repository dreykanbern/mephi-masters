# AddProject

Восьмой урок — исправляю синтаксис программы и использую возвращаемое значение метода `add`.

[Main](src/Main.java) · [Как запустить](../../../README.md)

Добавляю знак `=` в объявление `value`, точки с запятой после инструкций в `main` и фигурные скобки вокруг тела метода `add`.

Метод `add(int x, int y)` возвращает сумму аргументов. Первый вызов `add(3, 4)` даёт `7`, второй — `add(7, 10)` — даёт `17`.

Результат и ответ для поля задания: `17`.
