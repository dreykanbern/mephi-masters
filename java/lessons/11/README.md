# Урок 11 — Сравнение имён без учёта регистра

Задание 3 из блока о строках. Сравнить имена `Иван Иванов` и `иван иванов` в системе, где регистр не важен.

Решение на Java 17: [`Main.java`](src/Main.java). Метод `equalsIgnoreCase` выводит `true`: имена совпадают без учёта регистра, поэтому пользователю нужно выбрать другое имя.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
true
```
