# Урок 14 — Длина уникального имени

Задание 6 из блока о строках. Дополнить `checkUserName`: если имя уникально, сообщить его длину с помощью `length`.

Решение на Java 17: [`Main.java`](src/Main.java). Для проверки имя изменено с `Иван Иванов` на `Вован Иванов`. Пробел тоже входит в длину строки.

Запуск из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Результат:

```text
Отличное имя!
Ваше имя имеет длину 12 символов
```

Для имени `Иван Иванов` выводится только `Выберите другое имя пользователя`.
