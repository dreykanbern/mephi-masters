# Домашнее задание 1 - Калькулятор

## Запуск

Из этого каталога:

```bash
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

Дробные числа ввожу через точку.

## Ответы на вопросы

1. Какой оператор лучше использовать, чтобы проверить, какую операцию выполнять?

   Для выбора операции использую `switch`: каждому знаку соответствует свой
   `case`. Так проще увидеть, какое действие выполняется для `+`, `-`, `*` или `/`.

2. Если пользователь ввел неподдерживаемую операцию, стоит ли ему сообщить об этом?

   Да, нужно вывести сообщение об ошибке, чтобы пользователь понял, что такой
   операции нет. Текущий результат при этом сохраняется, и можно ввести другой
   оператор.

3. Нужна ли дополнительная переменная для второго операнда? А для результата?

   Для второго числа использую `secondOperand`. В `result` сначала храню первое
   число, а после операции записываю результат. Отдельная переменная для первого
   числа не нужна: в следующем вычислении его роль выполняет уже полученный
   результат.

4. Можно ли написать весь код в одном методе? Или вынести код для каждой операции в отдельный метод?

   Можно написать всё в `main`, так я и сделал: операции короткие, и весь порядок
   ввода виден в одном месте. Каждую операцию можно вынести в отдельный метод,
   если в дальнейшем вычисления станут сложнее.

5. Как обрабатывать команды управления калькулятором (например, сброс результата или завершение работы)?

   Проверяю команды внутри цикла. `C` обнуляет результат, отменяет выбранную
   операцию и возвращает к вводу первого числа. `S` завершает цикл. Использую
   `equalsIgnoreCase`, поэтому, например, `c` и `C` означают один и тот же сброс.
