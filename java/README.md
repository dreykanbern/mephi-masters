## Как запустить урок

Из папки `java`, на примере первого урока:

```bash
cd lessons/1/ExampleProject
javac -encoding UTF-8 --release 17 -d out src/*.java
java -cp out Main
```

В IntelliJ IDEA выбираю JDK 17. Каждый учебный проект подключаю как отдельный Java-модуль, а его папку `src` отмечаю как Sources Root. Но это достаточно затратно и этот подход был упрощен в пользу скорости добавления большого количества задачек.
